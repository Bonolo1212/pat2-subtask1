# pat2-subtask1
Morse code is a communication system that represents letters, numbers, and symbols using sequences of short and long signals called dots and dashes. It was one of the first methods of long-distance electronic communication and played a major role in global communication before telephones and the internet.
The system is closely associated with Samuel Morse, who helped develop the electric telegraph in the 1830s and 1840s.
History of Morse Code
Early Development
In the early 19th century, long-distance communication was slow and depended on physical transport such as horses or ships. The invention of the electric telegraph changed this.
Samuel Morse and his collaborators developed:
the electric telegraph
a coding system to send messages through electrical pulses
The first famous Morse-coded message was sent in 1844 between Washington, D.C. and Baltimore:
“What hath God wrought”
American vs International Morse Code
Two main versions existed:
American Morse Code — used mainly in the United States
International Morse Code — standardized later and still used today
International Morse code became the global standard because it was simpler and more reliable.
How Morse Code Works
Each character is represented by:
Dot (.) = short signal
Dash (-) = long signal
